# Referências originais

Os arquivos em `original/` preservam os materiais recebidos no início do projeto.
Eles ajudam a consultar detalhes, requisitos e direção visual, mas não são a fonte
canônica das decisões atuais.

## Atenção ao interpretar

- STYLE e Find your Style são nomes antigos.
- A proposta multi-nicho foi substituída pelo foco em beleza e bem-estar.
- Produtos vistos no protótipo não fazem parte do AgendaShops.
- O primeiro produto é web responsivo.
- Agendamentos não são confirmados automaticamente; dependem do parceiro.

Em caso de conflito, siga o `AGENTS.md` da raiz e os documentos numerados em
`docs/`.
